# Design Pattern learning note

## Classes & Objects 
```
Understand that a class is a blueprint and an object is a specific instance built from that blueprint, each with its own state.

🧠 The Idea (Theory)
- A class groups related data (attributes) and behavior (methods) under one name.
- An object (or *instance*) is a concrete thing built from the class, with its own copy of the attributes.
- Analogy: the class `Character` is the *character sheet template* in a tabletop RPG; each object is one filled-in sheet (Aragorn's sheet, Gandalf's sheet). Both sheets follow the same template but hold different values
```
